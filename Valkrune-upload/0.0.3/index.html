Damage Skip Investigation

Why some clean hits silently disappeared in multiplayer

The fix: The 100ms invulnerability window after each hit was originally added to prevent literal same-frame double-hits. In multiplayer where attackers cluster within a few frames of each other, that window was eating 5–15% of legitimate hits with zero visual feedback. Lowering damageCooldown from 0.10f → 0.03f (30ms) preserves frame-protection while letting normal MP attack-clusters land. Soul Shield (49% of skipped events) is intentional defensive behavior — confirmed correct.

Why it matters: 120ms is below human reaction time — the character was gone before the player could process the killing blow. The new HOLD phase keeps the body visible long enough to register the killer, the direction, and the surrounding state, then fades cleanly. Applies globally to all actors (humans + bots) for visual consistency. Inspired by Brawl Stars and Apex Mobile death cams.

Under the Hood

Tooling and diagnostics for the long road ahead
New System

INVENTORY Documentation Pattern

Six markdown files capturing public API, NetworkVariables, lifecycle hooks, skip-lists, and grep-verify commands for the most regression-prone files. Each delivery now passes a pre-flight check against these inventories — designed to catch stale-file regressions before they reach a build.

  • _README.md — Master index + protocol
  • EnemyHealth_INVENTORY.md
  • MultiplayerRemoteSlotLinkSync_INVENTORY.md
  • BotSpawnManager_INVENTORY.md
  • MatchActorCombatPresentation_INVENTORY.md
  • MatchScoreboardNetworkSync_INVENTORY.md
Dev Tools

Diagnostic Flags Retained

Off by default — toggle in Inspector when chasing edge cases. Server-side logs designed to give a clear chain-of-evidence without rebuilding. The 0.0.3 damage-cooldown fix came directly from the data these flags surfaced in earlier sessions.

  • [CombatVFX-DIAG] — VFX shader resolution
  • [EnemyHealth-VFX-DIAG] — Hit/shock-ring shaders
  • [Whirlwind-DIAG] — Broadcast trace (server + client)
  • [DataBuilder] ROW — Endscreen row-state per slot
  • enableDeathTimingDebug — Death sequence timing
  • enableDamageSkipDebug — Why a hit was silenced
